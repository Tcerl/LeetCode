# 🔍 REVIEW — Hệ thống chữa bài & mở rộng kiến thức

> Đây là trung tâm **học tập sau làm bài**. Mỗi lần chữa bài đúng cách sẽ nâng trình độ nhanh hơn làm thêm 5 bộ đề mới mà không hiểu lý do sai.

---

## 📁 Cấu trúc thư mục

```
Review/
├── README.md                 ← File này
├── Daily_Review/             ← Chữa bài theo ngày
│   └── YYYY-MM-DD_Set_XXX.md
├── Vocab_Bank/               ← Ngân hàng từ vựng tích lũy
│   ├── 01_Business_Office.md
│   ├── 02_Finance_Banking.md
│   └── ...
└── Error_Analysis/           ← Phân tích lỗi sai theo dạng bài
    ├── Listening_Errors.md
    ├── Reading_Grammar_Errors.md
    └── Reading_Vocab_Errors.md
```

---

## 📚 Hướng dẫn Vocab_Bank

Mỗi file vocab theo chủ đề có format:

```markdown
# [Chủ đề] Vocabulary

| # | Word | Type | Meaning (VI) | Collocations | Example | Status |
|---|---|---|---|---|---|---|
| 1 | allocate | v | phân bổ | allocate budget/resources | The company allocated $5M for R&D. | ⬜ New |
| 2 | ... | | | | | |

**Status:** ⬜ New | 🟡 Learning | 🟢 Mastered
```

## 📊 Error Analysis — Phân tích lỗi theo tuần

Cuối mỗi tuần, tổng hợp lỗi sai vào file tương ứng:

```markdown
## Tuần [X] — [Ngày bắt đầu] đến [Ngày kết thúc]

### Top lỗi Listening
- Part 2: Nhầm câu hỏi gián tiếp (X lần)
- Part 3: Không đọc câu hỏi kịp trước khi nghe (X lần)

### Top lỗi Reading  
- Part 5: Nhầm từ loại (adj/adv) (X lần)
- Part 7: Đọc không kỹ đoạn đôi (X lần)

### Kế hoạch cải thiện tuần sau
- [ ] ...
```
