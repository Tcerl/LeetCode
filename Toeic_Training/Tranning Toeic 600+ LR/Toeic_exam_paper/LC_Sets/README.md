# 🎧 LC_Sets — Buổi nghe có cấu trúc

> Repo **không chứa file audio** (bản quyền ETS). Mỗi "buổi nghe" = 1 đề/đoạn từ nguồn ngoài + quy trình cố định.
> Xem `LC_01/guide.md` để có mẫu chi tiết. File này là **giao thức chung + tracker 20 buổi**.

---

## Quy trình mỗi buổi — 3 lần chạm

| Lần | Việc | Thời gian |
|---|---|---|
| **1** | Làm như thi: nghe 1 lần, chọn ngay, **không** đọc script | = độ dài đề |
| **2** | Nghe lại + mở transcript. Dừng ở mỗi chỗ nghe hụt. Ghi câu sai + từ nghe hụt | ~1.5× |
| **3** | Tắt script, nghe chay lại. Nói nhại (shadowing) 5–10 câu | ~1× |

Câu sai → `../../Review/Error_Analysis/Listening_Errors.md` kèm lý do (nghe hụt từ / nối âm / bẫy lặp từ / không hiểu nghĩa).
