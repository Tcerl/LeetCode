# 🎯 DRILLS — Ngân hàng câu luyện theo Part

> Mục đích: nội dung **tự chứa, mở điện thoại cày được ngay** ở bất cứ đâu (GitHub app / web).
> Khác với `Toeic_exam_paper/` (đề full 200 câu): ở đây chia nhỏ theo **dạng bẫy**, làm 10–30 câu mỗi lần.

---

## Cách dùng

1. Mỗi file: phần **Câu hỏi** ở trên, **Đáp án & giải thích** ở dưới. **Không kéo xuống trước khi làm hết.**
2. Tự bấm giờ. Part 5: mục tiêu **≤ 20 giây/câu**.
3. Làm xong → chấm → câu sai chép sang `Review/Error_Analysis/Reading_Grammar_Errors.md` kèm **lý do thật** (không biết từ / sai luật / bẫy nào).
4. Cuối tuần: làm lại đúng các file có nhóm bẫy mình hay sai.

## Cấu trúc

```
Drills/
├── Part5_Grammar/       ← từ loại, thì, hòa hợp, đại từ, giới từ, liên từ, mệnh đề QH, so sánh
├── Part2_QR/            ← Question-Response theo dạng (Wh / Yes-No / Tag / gián tiếp)
├── Part6_TextCompletion/ ← đoạn văn + 4 chỗ trống
└── Part7_Reading/       ← single / double / triple passage theo chủ đề
```
